# Vance Coach Gateway 核心能力

## 1. 实时语音陪练与 Vance Soul

- MiniMax Realtime：语音转写、实时文本与 PCM 音色输出。
- Vance 人格：热情、专业、不施压；每轮给一个最优先的下一步。
- 覆盖减脂日、训练中陪伴和情绪支持；疼痛、头晕、胸闷等异常优先停训与求助。

## 2. 健身房器械识别

- Kimi K2.6 识别照片中的可确认器械。
- 仅 `high` 返回为可用设备；`medium` 只请求用户确认；`low` 直接丢弃。
- 模块只输出器械事实，不生成训练计划；语音教练用上下文继续给建议。

## 3. 语音体验质量与安全

- 24kHz 单声道 PCM WebSocket 通道，支持手动按住说话与自动聆听。
- 自动聆听先校准环境噪声，默认严格阈值为基线 +18dB，过滤短杂音。
- 空音频提交由端和 Gateway 双重拦截；上游音频错误会自动重连。
- 开发评估可记录转写、首字/首音时延和人工标注；原始麦克风音频不落盘。

## 非当前承诺

- 动作资料库尚未接入实时建议链路。
- 完整日计划、Apple Health/穿戴数据、正式云端记忆需要由主 App 继续实现。
