## 1.1 One wish, several training directions

### Scenario

Maya 说：

> 我想减脂，也想让自己体力好一点。每周大概能去三次健身房，但我不想
> 每次都待两个小时。

Question:

**你觉得她只需要去跑步吗？**

- 对，减脂就应该只做有氧
- 不一定，她可能需要不止一种训练
- 我不知道

Feedback for first choice:

跑步可以增加有氧活动，但它没有包办 Maya 的全部目标。她还提到了体力、
时间和长期坚持。力量训练、其他有氧活动、日常活动和饮食都会影响结果。

Feedback for second choice:

对。我们还不能立刻替她排计划，但已经知道不该把“减脂”翻译成一张只有
跑步的课表。

Feedback for unsure:

这个问题本来就没有只看一个词得出的答案。下一步要问的是：她最想先改善
什么，以及她愿意长期做什么。

---

## 1.2 What different goals ask from training

### Learn card · Strength

**如果你想变得更有力量**

计划需要让你反复练习几个动作，并逐渐增加能稳定完成的负荷。你不必一开始
就测试最大重量。

Observe over time:

- 相同动作能否使用更重的重量
- 原来的重量是否变得更容易控制
- 日常搬、提、起身是否更轻松

### Learn card · Muscle

**如果你想增加肌肉**

训练需要让相关肌群得到足够、可恢复的练习量。器械和自由重量都可以用，
也不需要每一组都做到完全失败。

Observe over time:

- 每个主要动作每周完成了多少有效练习
- 重量或次数是否缓慢上升
- 睡眠、疲劳和身体尺寸的长期变化

### Learn card · Cardio

**如果你想让心肺和耐力更好**

你需要持续做让心率和呼吸上升的活动。快走、骑车、游泳、跑步和划船机都
可以成为有氧训练，形式不必固定。

Observe over time:

- 同样路线是否没有以前那么喘
- 相同时间能否走、骑或跑得更远
- 恢复到正常呼吸所需的时间

### Learn card · Body composition

**如果你想减脂或管理体重**

训练很重要，但体重变化不会只由某一个动作决定。力量训练帮助你维持和发展
肌肉，有氧和日常活动帮助提高活动量；饮食、睡眠和长期执行也会参与结果。

Vance 不用一次训练消耗的卡路里判断它是否值得做。

### Learn card · Health and consistency

**如果你只是想让身体状态更好**

这也是完整的目标。规律活动可以服务于睡眠、情绪、血压、日常功能和长期
健康。对刚开始的人来说，从几乎不动变成稳定活动，本身就是很大的变化。

---

## 1.3 Choose a lead goal

**如果未来四周只能优先观察一件事，你最想看到什么变化？**

Choices are populated from onboarding. User selects one as `leadGoal`.

Vance:

这次选择只服务于第一版计划，以后随时可以改。先给它一个方向，避免每个目标
都想同时拉满。

Next question:

**还有哪个目标，你不想在这四周完全放掉？**

User selects one optional `supportGoal`.

Example result:

> 主要目标：爬楼时不那么喘
>
> 同时保留：每周两次力量训练

---

## 1.4 Define evidence you can actually see

Question:

**四周以后，什么会让你觉得这套计划有用？**

Suggestions change with the selected goal:

- 我能完成每周计划的大部分内容
- 同样的快走路线更轻松
- 我能稳定完成第一次全身训练
- 两个主要动作增加了重量或次数
- 我的精力或睡眠有改善
- 自定义

Vance:

体重和外观可以记录，但不要让它们成为唯一证据。训练本身的完成度、能力和
身体感受，通常会更早告诉你计划是否合适。

---

## 1.5 First constraint

Use the user's schedule answer.

**你说自己通常能训练：每周 2–3 次，每次约 45 分钟。哪种开局更像真实生活？**

- 先安排每周 2 次，做稳以后再加
- 直接安排每周 3 次
- 每周情况不同，需要 A / B 两个版本

Feedback:

- Start with two: 这是保守但可靠的开局。第三次可以先作为可选活动。
- Start with three: 可以。我们会让单次训练保持在你的时间内。
- A/B version: 最终计划会同时给你完整周和忙碌周，不需要临时从零决定。

## 2.1 Find the zones

### Scene

Show a gym floor photo or illustrated map.

Tap targets:

- 有氧区：跑步机、单车、椭圆机、划船机
- 固定器械区：动作轨迹大多由机器引导
- 自由重量区：哑铃、杠铃、训练凳和深蹲架
- 开放训练区：垫子、弹力带、壶铃或自重训练空间

Vance:

区域名称不代表难度。固定器械和自由重量都是工具；这一阶段先使用容易设置和
观察的工具。

Question:

**如果今天只想熟悉环境，下面哪种做法最合适？**

- 每个区域都练到很累
- 走一圈，记住出口、饮水处和两台想试的器械
- 找最重的哑铃测试一下

Correct feedback:

先知道东西在哪里，下次进门就会少做很多临时决定。

---

## 2.2 Read a machine before using it

### Coach copy

第一次看到一台器械，不用急着坐上去。

先找找座椅下面或侧面的拉杆，看看靠背能不能移动，再找到配重旁边的插销。
不同器械的调节方式不完全一样，但你至少要确认：坐上去以后，握把和转轴
大致对得上你的身体；动作开始的位置不会让你被迫拉伸；所有调节部件已经
卡紧。

如果你不知道某个拉杆控制什么，先空载或用最轻重量试一下。旁边有人使用时
不要动它，也不要在配重悬空时拔插销。

### Image interaction

On a machine photo, user taps any visible controls. Each tap reveals its job:

- Seat lever: 改变身体相对把手和转轴的位置
- Back pad: 改变支撑和动作起点
- Range limiter: 缩小或扩大可移动范围；不是每台器械都有
- Weight pin: 选择配重片；必须完整插入
- Instruction plate: 查看动作名称、调节提示和重量单位

---

## 2.3 kg, lb, and the weight stack

### Coach copy

配重上的数字可能是公斤，也可能是磅。20 kg 大约是 44 lb，所以只比较数字
会让你误判重量。今天不要求换算，只要求先看单位。

有些器械还会通过滑轮改变你实际感受到的阻力。换了机器以后，即使数字相同，
体感也可能不一样。把每台机器的重量当成自己的记录，不用拿它和另一台硬比。

Question:

**上周你在 A 器械用了 20，今天换成 B 器械。最稳妥的做法是什么？**

- 直接使用 20，因为数字一样
- 从容易控制的重量开始，再根据当组表现调整
- 先测试自己最多能做多少

Feedback:

机器、单位和动作都可能不同。先做一组轻的，观察比猜测可靠。

## 2.5 Gym etiquette that removes uncertainty

Swipe cards:

**有人坐在器械上休息，我不确定他是否做完了。**

可以直接问：“你好，你还剩几组？” 如果对方愿意，也可以询问是否轮流使用。

**我想调座椅，但不知道拉杆在哪。**

先看器械侧面的说明图；仍然找不到时，问工作人员比用力掰动部件更安全。

**做完以后需要做什么？**

把个人物品带走，按场馆规则擦拭接触面。不要替下一位用户预设重量。

# Day 3 · 推和拉：认识上半身动作

## Cover

**DAY 03 · BUILD A HUMAN**

今天把动作分成“推”和“拉”。这比死记一串肌肉名字更快，也更容易拿来排计划。

你会试一台推的器械和一台拉的器械。重量保持很轻，每台只做几次。

Action: `打开 Body Map`

---

## 3.1 Build a Human · push

### Interaction

Model stands with upper arms opened slightly. User drags both hands forward.

Prompt:

**像把一扇重门推开。你觉得哪里可能参与最多？**

- 胸部
- 背部
- 小腿
- 不确定

After interaction:

胸大肌会帮助上臂向身体前方移动；肱三头肌帮助伸直手肘，肩部也会参与。
坐姿推胸本来就是多个关节和肌群一起完成的动作。我们关注整套动作能否稳定
完成，以及主要负荷是否落在预期区域。

Body Map lights: chest, front shoulder, triceps.

---

## 3.2 Chest press setup

**找到坐姿推胸 / Chest Press。**

Coach copy:

坐下后先看看把手在哪里。如果它明显高过肩膀或低到腹部，先调座椅，让把手
来到胸口附近。背部靠住靠垫，脚能稳定踩地，再选择一个你确信很轻的重量。

动作开始时不需要追求很深的拉伸。推出时保留自然的手肘空间；回程慢一点，
不要让配重片撞回去。

### Predict

**如果座椅太低，把手跑到肩膀上方，你会先怎么处理？**

- 把重量加大，让动作更稳
- 调高座椅，再用轻重量试几次
- 忍着做完这一组

Feedback:

先改变位置，再判断重量。调节后仍然不舒服，就停止这台器械，不需要把身体
塞进机器设定的轨迹里。

### Try

Do 5 slow reps.

Prompt after set:

**刚才最明显的是什么？**

- 胸和手臂一起用力
- 主要是手臂累
- 肩部不舒服
- 整体很轻，还不太确定

Feedback:

- Chest and arms: 这是常见的推。先记录，不需要追求某一块肌肉完全孤立。
- Arms: 也可能发生。下一次先确认座椅和节奏，不要立刻用更大重量寻找胸感。
- Shoulder discomfort: 停下来。可以重新调节起点和座椅；仍不舒服就换动作。
- Unsure: 第一组能稳定完成已经足够。身体感受会在重复比较中变清楚。

---

## 3.3 Build a Human · pull

### Interaction

Model starts with arms in front or overhead. User drags elbows toward the torso.

背阔肌和上背部会参与把上臂拉向身体；肱二头肌帮助弯曲手肘。肩胛骨会移动，
但不需要在每一次拉动前用力把它们永久夹死。

Body Map lights: lats, upper back, biceps.

Question:

**下面哪个动作属于“拉”？**

- 坐姿推胸
- 高位下拉
- 腿举

---

## 3.4 Choose one pull machine

User chooses based on availability:

- 高位下拉 / Lat Pulldown
- 坐姿划船 / Seated Row

### Lat pulldown instructions

把大腿挡板调到能帮助你坐稳的位置。握住把手后，胸口保持自然抬起，把手
拉向上胸附近。身体可以有少量自然移动，但不要靠大幅后仰把重量甩下来，也
不要把横杆拉到颈后。

### Seated row instructions

脚踩稳，坐到你不需要耸肩才能够到把手的位置。拉动时让手肘经过身体两侧，
把手来到腹部附近；回程时手臂向前伸，但身体不用跟着前后摇摆。

### Try

Use a light weight for 5 reps.

Prompt:

**这一组有没有出现下面的情况？**

- 我可以平稳拉动和放回
- 手臂参与很多
- 我会不自觉地耸肩
- 我需要摆动身体才能完成
- 有不舒服或疼痛

Feedback:

手臂参与并不代表动作失败。耸肩或摆动明显时，先减轻重量，再看看能否用更
安静的身体完成。出现疼痛时停止，不用继续比较。

---

## 3.5 Compare push and pull

Show the two saved sets side by side.

Prompt:

**不用看动作名称，你会怎么描述它们？**

- 推：我把重量从身体 `推开 / 拉近`

# Day 4 · 膝和髋：认识下半身动作

## 4.1 Build a Human · knee and hip

### Interaction A

User bends the model's knees and hips as if sitting into a chair.

Copy:

从站立到坐下，膝盖和髋部都会弯曲。大腿前侧、臀部和其他肌群一起帮助你
减速，再把身体推回站立。

### Interaction B

User moves the model's hips backward with only a small knee bend.

Copy:

当髋部更多地向后移动，大腿后侧和臀部会承担不同的工作。这个动作常被称为
髋铰链。膝盖仍然可以自然弯曲，背部也不需要刻意压成僵硬的直线。

---

## 4.2 At-home contrast

Only proceed near a stable chair and with no current pain.

### Round A · sit to stand

从稳定的椅子上站起，再慢慢坐回去，做 5 次。脚掌留在地面，选择一个自然
站距。可以用手扶住固定支撑。

Observe:

- 起身时大腿前侧、臀部或两者都有感觉
- 膝盖和脚尖大致朝相近方向移动
- 我需要把椅子调高或使用手部支撑
- 有不舒服，停止

### Round B · hip hinge

双脚站稳，膝盖稍微放松。想象身后有一扇抽屉，用臀部把它关上。髋部向后时，
上半身会自然前倾；只做到你仍然舒服、能控制的位置，做 5 次。

Observe:

- 大腿后侧有拉长或用力感
- 臀部向后时能保持平衡
- 我更像在向下蹲，还没找到髋向后的感觉
- 有不舒服，停止

Vance:

两种做法都不是错误版本。它们让下半身处理不同的任务，之后可以对应到腿举、
深蹲、硬拉和许多日常动作。

## 4.3 The stance experiment

### Setup

1. 使用你自然选择的站距。
2. 脚稍微宽一点，脚尖可以自然向外一些。

Question:

**哪一个更容易保持脚掌着地、膝盖舒服、身体平衡？**

- 第二种
- 差不多
- 两种都不舒服

Feedback:

身体比例、活动范围和经验会影响舒服的站距。保留更稳定的版本即可。两种都
不舒服时不要继续缩小或放大站距来测试极限。

## 4.4 Machine lab · leg press

**找到坐姿腿举 / Leg Press。**

Coach copy:

先把座椅调到一个不拥挤的位置。双脚踩在踏板上，腰背得到靠垫支撑。解除
安全装置前确认你知道怎样重新锁回去；不确定时请工作人员示范。

下降时让膝盖和髋部一起弯曲，只走到腰背仍然稳定、膝盖没有不适的位置。
推回时不用把膝盖猛地锁到底。

### Predict

**如果下降到某个位置时，腰背开始离开靠垫，你会怎么做？**

- 缩短到自己能稳定控制的范围
- 加重量把身体压住

Feedback:

- 座椅太远，动作范围很小

- 我不知道怎样解除或锁回安全装置

Feedback routes directly to: adjust, stop, or ask staff.

## 5.1 Decode 3 × 10

Show: `Chest Press · 3 × 10 · rest 90 sec`

Interactive labels:

- Chest Press: 动作
- 3: 组数；完成一轮次数后休息，再开始下一组
- 10: 每组计划次数
- 90 sec: 两组之间的休息

Question:

**这行计划要求连续完成 30 次吗？**

- 是
- 不是，中间有两次组间休息

Feedback:

先做 10 次，休息，再开始下一组。休息不是偷懒，它会影响下一组能否继续
保持重量、节奏和动作质量。

---

## 5.2 Reps are a target range, not a trap

Show: `2 × 8–12`

Coach copy:

8–12 次表示一个范围。假设你做到第 10 次已经无法保持控制，不需要为了碰到
12 而硬做；如果 12 次结束后仍然非常轻松，也不代表这一组作废。把实际完成
的次数和感受记下来，下一组或下次再调整。

Scenario:

你计划做 8–12 次。第 9 次开始必须借助摆动身体才能完成。

Choices:

- 继续摆到 12 次
- 在动作失控前结束，并记录 9 次
- 立刻加重量

Feedback:

记录真实完成的次数，比把计划数字做满更有用。

---

## 5.3 Find a starting weight with RIR

### Coach copy

做完一组以后，问自己：如果保持刚才的动作范围和节奏，我大概还能做几次？
这叫做 RIR，也就是“还剩几次”。它不是精确测量，刚开始估得不准很正常。

Use one mastered movement. Complete 8 reps with an easy load.

Question:

**如果保持刚才的控制，你觉得还能做几次？**

- 还能做 5 次以上
- 大约还能做 2–4 次
- 可能只剩 0–1 次
- 动作已经开始失控
- 说不清

Feedback:

- 5+: 这是很轻的练习组。你可以保持它熟悉动作，或下组增加最小一档。
- 2–4: 对多数初学练习来说，这是一个可用的起点。先观察下一组是否一致。
- 0–1: 今天先减轻。第一版计划不需要频繁逼近极限。
- Lost control: 结束这一组并减轻重量，或减少计划次数。
- Unsure: 保持重量，多做一组并记录。RIR 是在比较中学会的。

---

## 5.4 Rest changes the next set

### Mini experiment

1. 用刚才的重量完成 8 次。
2. 休息 60–90 秒。
3. 再完成 8 次。
4. 比较两组最后两次的速度和控制。

Question:

**第二组怎么样？**

- 和第一组接近
- 明显更吃力，但仍能控制
- 次数或动作质量下降很多
- 我休息后还没有准备好

Vance:

休息时间不是固定道德标准。大动作、较重重量或接近力竭的训练通常需要更久
恢复。今天若还没准备好，可以多休息一会儿，而不是按秒数强行开始。

---

## 5.5 What progression actually looks like

### Four training logs

- Week 1: Chest Press · 20 kg · 2 × 8
- Week 2: Chest Press · 20 kg · 2 × 10
- Week 3: Chest Press · 20 kg · 2 × 12
- Week 4: Chest Press · 22.5 kg · 2 × 8

Question:

**这四周有没有进步？**

- 有，先增加次数，再增加重量
- 没有，只有每周都加重量才算
- 不确定

Feedback:

进步可以是更多重量、更多可控次数、更好的动作质量，或相同训练变得更轻松。
不需要每一次都同时增加所有变量。

### Rule builder

User completes:

> 当我能用当前重量完成所有计划组数和次数，并且仍有大约 **{2–4}** 次余量，
> 下次可以 **{增加最小重量 / 先保持一次}**。

Vance:

睡眠差、压力大或身体状态不同时，保持或降低也属于正常训练记录。

# Day 6 · 力量和有氧怎么一起练

## Cover

**DAY 06 · WEEK BUILDER**

力量训练和有氧训练不是二选一。它们解决的问题不同，也可以出现在同一周，
甚至同一次训练里。

今天会先判断有氧强度，再根据你的主要目标安排先后顺序。

Action: `打开一周日历`

---

## 6.1 What counts as cardio?

### Coach copy

只要活动持续让心率和呼吸比平时更高，就可能构成有氧活动。快走、骑车、
游泳、跑步、舞蹈和许多球类都可以算。器械屏幕上的卡路里不决定这次活动
有没有价值。

### Sort interaction

Sort each item into `可以是有氧` or `不一定`:

- 快走 25 分钟
- 骑车通勤
- 椭圆机
- 跑步
- 连续搬箱子上楼
- 做一次肱二头肌弯举

Feedback:

活动名称不是唯一标准。持续时间和当时强度都会改变它对心肺的要求。

---

## 6.2 Use the talk test

### Moderate effort

呼吸明显比平时快，但还能说出完整句子。对很多初学者来说，这是建立基础
有氧量时容易控制的强度。

### Vigorous effort

呼吸很急，只能说出几个词就需要换气。这种强度不是必需品，也不适合拿来
填满每一次有氧训练。

### Try

Choose one:

- 快走或跑步机 5 分钟
- 单车或椭圆机 5 分钟
- 原地走动 5 分钟
- 今天只学习，不实操

After minute 3:

**现在说一句完整的话，最接近哪种情况？**

- 可以自然说完，几乎不喘
- 可以说完，但呼吸明显加快
- 只能说几个词
- 有头晕、胸痛或异常呼吸困难

Feedback:

- Easy: 这是轻强度。可以作为热身、恢复或增加日常活动。
- Moderate: 这是可以持续积累的中等强度。
- Vigorous: 这是较高强度。新手不需要用它完成全部有氧时间。
- Warning: 立即停止，不继续强度实验。

---

## 6.3 How much belongs in a week?

### Coach copy

公共健康指南给成年人的长期方向，是每周累计 150–300 分钟中等强度有氧，
或 75–150 分钟高强度有氧，并在至少两天进行覆盖主要肌群的力量活动。

第一周不必立刻做到这些数字。很久没有运动的人可以从少量开始，再逐步增加。
你的第一版计划首先要能完成，然后才谈接近长期目标。

### Starting options

Based on profile, Vance suggests one editable starting point:

**Option A · 从几乎没有运动开始**

- 2 次全身力量练习，每次 25–40 分钟
- 2–4 次 10–20 分钟轻到中等强度活动
- 其余时间用散步和少坐补充

**Option B · 已经有一些活动习惯**

- 2–3 次力量练习
- 每周累计约 90–150 分钟中等强度有氧，再根据恢复增加

**Option C · 时间每天都不同**

- 两次必须完成的短力量训练
- 三个可移动的 10–20 分钟有氧块
- 状态好时再把其中一块延长

The app must label these as starting templates, not universal prescriptions.

---

## 6.4 Strength first or cardio first?

### Scenario

你只有 45 分钟，今天既想练力量，也想骑车。

Question:

**最应该先看什么？**

- 网上谁说的顺序最燃脂
- 今天最重要的训练目标
- 哪台器械离门最近

Feedback:

把需要最高技术、力量或专注度的内容放在自己精力更完整的时候。若力量是
主要目标，通常先完成力量，再做有氧；若正在准备跑步或骑行目标，可以把关键
有氧训练放在前面，或分到不同日子。

轻松的步行、单车或椭圆机可以放在力量训练后。很长或很累的有氧可能影响你
当天的力量表现，这时分开安排会更舒服。对一般初学者，先把两种活动稳定做进
一周，比纠结完美顺序更重要。

---

## 6.5 Match the week to the goal

### Goal: general health

Use a mix of full-body strength and aerobic activity. Neither needs to disappear.

Example:

- Mon: 全身力量
- Tue: 快走 20–30 分钟
- Thu: 全身力量
- Sat: 喜欢的有氧活动 30 分钟

### Goal: muscle or strength

Protect the quality and recovery of resistance training. Aerobic work can remain,
but hard lower-body cardio should not repeatedly exhaust the same sessions that
need strong leg performance.

Example:

- Mon: 全身力量
- Wed: 中等强度单车 20–30 分钟
- Fri: 全身力量
- Weekend: 轻松步行

### Goal: cardio fitness

Keep two strength exposures if possible, then give the key aerobic sessions the
best place in the week.

Example:

- Mon: 轻松有氧
- Tue: 全身力量
- Thu: 重点有氧训练
- Sat: 全身力量或短力量 + 轻松有氧

### Goal: fat loss

Do not turn every day into punishment cardio. Keep resistance training, choose
aerobic activities you can repeat, and increase daily movement. Nutrition and
recovery need their own plan outside this Level 1 course.

Example:

- Mon: 全身力量
- Tue: 快走
- Thu: 全身力量
- Sat: 单车、游泳或较长步行
- Most days: choose one small way to sit less or walk more

---

## 6.6 Build full week and busy week

### Full week

User places:

- Required strength sessions
- Aerobic blocks
- Optional movement
- At least one recovery-aware gap after demanding sessions when needed

### Busy week

Prompt:

**如果下周突然少了两小时，你最想保住什么？**

The app guides the user to preserve:

1. A minimum number of strength sessions aligned with the goal.
2. Short aerobic or walking blocks that can move between days.
3. No attempt to squeeze every missed session into one exhausting day.

Natural copy:

运动。

# After graduation · four-week review

This is not part of the seven-day completion requirement, but it is the bridge
from Learn Mode into Train Mode.

## Weekly check-in

- 计划完成了多少？没完成的主要原因是什么？

## Four-week review

Compare against the evidence selected on Day 1:

- Keep: 哪些安排已经适合现实生活
- Change: 哪些内容总是被跳过或恢复困难
- Progress: 哪些动作可以增加重量、次数或组数
- Learn next: 哪台器械或哪个动作模式值得进入 Level 2

# Product writing rules

## Vance should sound like

- a calm coach standing beside the learner;
- specific about the next physical action;
- comfortable saying that several options can work;
- curious about what the learner observed;
- willing to leave a question open until there is enough evidence.

## Avoid these sentence habits

Do not repeatedly use:

- “你学会的不是 X，而是 Y。”
- “这不是 X，这是 Y。”
- “只需要记住三个问题。” when the number is arbitrary
- “你找到了你的胸 / 背 / 臀。” as if one sensation proves anatomy
- one-line inspirational conclusions after every screen
- “完美姿势”“标准答案”“最佳动作” without context
- declaring an exercise safe from a photo, checklist, or pain report

## Prefer

- a concrete scene before an explanation;
- complete conversational paragraphs mixed with short UI labels;
- “先试轻一点，看看下一组发生什么” over abstract encouragement;
- “这次观察到什么” over “答对了吗”;
- referencing the learner's saved goal, time, venue, and feedback;
- explaining why the plan changed.
